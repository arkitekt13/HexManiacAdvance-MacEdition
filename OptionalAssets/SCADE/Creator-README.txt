Kudos! This patch is made for testing purposes of CFRU Expansion and DPE-gen9.
This contains said features found in here: https://github.com/Shiny-Miner/CFRU-expansion
This is version of CFRU Expansion which dates 21/10/26

Files info:
- Data folder contains header files which contain information about species, moves, pokedex, items, abilities. You can see then using notepad.
- config.h contains major details like which feature is added, which feature is removed, flags and vars and more. Basically, lines having // before #define are features that are not there/removed.
- CFRU_documention.docx and pdf are included from original CFRU source.
- The SCADE.bps is to be patched to your clean 1.0 fire red or squirrels. Then place SCADE.toml in same folder as your patched rom and name it same as your patched rom.
