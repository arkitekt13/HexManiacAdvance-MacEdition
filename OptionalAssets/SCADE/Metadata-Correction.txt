SCADE metadata compatibility corrections — November 15, 2026

The latest creator BPS is unchanged. Two TOML entries were corrected locally:

1. data.abilities.descriptions at 0x100B050
   received: [description<"">]data.abilities.names (390 entries)
   shipped:  [description<"">]317

   The actual pointer array has 317 entries, ending exactly at 0x100B544, where
   graphics.moves.backgrounds.all begins. The engine references at 0x1C4 and
   0x1367A8 point to this description table; 0x73960 points to the background table.
   Using 390 descriptions would overlap the background table by 292 bytes.
   The last description pointer is at 0x100B540. This repeats the verified count
   correction from November 11; the new creator metadata reintroduced the old count.

2. data.trainers.stats (743 entries)
   received address: 0x23EAC8 (legacy vanilla copy)
   shipped address:  0x1273168 (patched trainer-table reference at 0xFC00)

   The new ROM contains 23 references to the relocated table. All 743 records
   have valid struct types, class IDs, party sizes and party ranges. The table
   ends at 0x127A580, exactly where its first party data begins. The supplied
   743-record count and complete trainer format are retained. This prevents HMA
   from editing the legacy table instead of the patched trainer data.
